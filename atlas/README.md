# Project Atlas public review mirror

This directory publishes the generated, self-contained Project Atlas dashboard and Agent Harvester without Vercel Authentication. The source dashboard is in gendaiski/Project-Atlas, branch codex/chat-projects-20261024. The Agent Harvester is a single HTML file with 1,407 public prompt files from the pinned Agency Orchestrator source, with per-record provenance and license notes.

The dashboard is a static snapshot. Linked private repositories and protected applications may still require their own accounts. Neither page runs an agent or installs software.
