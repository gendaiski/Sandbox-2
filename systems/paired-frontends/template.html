Two frontends, one HTML file

xyOps: genuine v1.1.15 interface and assets, with a browser-local transport adapter. Create workflows, tickets and settings through the original controls. Browser-local task execution supports actual per-node output and errors; remote server plugins are not implemented locally. The scheduler, workers, actual servers, telemetry and integrations remain offline.

Altaflow: an independent implementation of publicly documented document-workflow flows. Its original private application source and authenticated interface were not available. Build a movable connected-node canvas, configure documents, fields, recipient steps, conditions, local approvals and local bots; execute the route and inspect real run states. It is not the vendor's original UI.

All application assets are embedded in this file. No backend, paid services, app login or network connection is needed. Current Safari/Chrome/Edge is required. This is a native web experience, not an installed Swift/iOS app. No example runs or successful remote jobs are preloaded.

Changes persist per browser/origin where storage is allowed. Otherwise they last for this tab only; use Backup before closing. Drafts from the separate hosted xyOps site are not silently copied here. The two apps keep their own draft keys.

The hosted copy retains the Altaflow site's existing owner-only access. The HTML file itself can be downloaded and opened without an application sign-in.
