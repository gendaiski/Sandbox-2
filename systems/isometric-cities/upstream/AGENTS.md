# Do this location

Apple Silicon macOS, everything local. `atlas.py make "LOCATION"` only prepares a registered source. Beauty and accurate colour come from your source work and review, steps 1 to 4. Each city gets a separate real map, explorer and film. Say plainly what you could not source or verify.

1. Run `./setup.sh`, then `python3 atlas.py make "LOCATION"`. Inspect the native source. Reuse bundled source PNGs for the two examples; `demo --open` needs no models. Unknown places start as an untextured OSM/terrain block model, 1024×640; widen the frame in a copied recipe for a larger map. Improve licensed imagery, geometry and real roof colours before changing prompts: find aerial, DSM or mesh data and write a `photographic` or `surface` recipe. With no such data the result stays a plain illustrative starter; report that. Fresh source-bound landmark inputs require remeasurement. [Sources](docs/sources.md).
2. Choose one recognisable landmark cluster and a literal native 1024-square crop. Set up models with `./setup.sh --models` (about 9 GB, non-commercial model terms; tell the user first). Styling runs in the isolated MFlux worker, or a compatible job queue named by `ATLAS_IMAGINE`. That worker has repainted the full Edinburgh example, 10 windows at about 2.5 minutes and 18 GB each, and painted the windows of a new Amsterdam map that an agent then finished with reviewed repairs; smaller Macs are untested, so report what actually ran. It needs Metal GPU access: if the worker log says `No Metal device available` (seen inside one coding agent's command sandbox), rerun outside the sandbox with a fresh `--out`; a failed job is never relaunched. One model at a time. Try at most two treatments in separate output directories.
3. Match NYC/Tiny London/SF: thin local-colour outlines, flat coherent shading, readable streets and source-supported roof differences. No clay. Compare real reference photos, native source and art for recognisable landmark silhouettes, measured scale, invented buildings, roofs and lost courtyards. A matching source/art pair can share the same wrong geometry. Save SHA-bound findings. Model completion is not geographic acceptance. Show the pilot beside its source and record the visual checks. Expand once they pass, unless the user requests an approval checkpoint.
4. Expand the accepted treatment with `atlas.py paint`; both source sides must reach 1024 pixels. Neighbours guide each next window; this is context infill, not joint denoising. Inspect overlap bands, landmarks and source-open parks for invented buildings. Open water invites invented islands: protect it with `paint --keep`. Keep failed studies outside Git. `atlas.py finish` replays reviewed colour masks or bounded native repairs with source, prior-pixel and asset hashes. Never reuse another city's masks or bypass a hash guard.
5. Export with `atlas.py showcase`, `atlas.py film` and `atlas.py social`. Preserve attribution in the viewer, metadata and sidecars. Films have zero text by default, optional anchored callouts at most seven words. No title or HUD. README GIFs use native held crops. [Commands, resume and review](docs/workflow.md).

Run tests before handing back. Bundled DC/Edinburgh examples must export offline, sources/art must retain their exact native registration, and no inference may silently shrink references. Keep the code small, source recipes explicit and captures/weights/results under ignored `outputs/`. Report actual source/art limits; do not equate byte checks with visual approval.
