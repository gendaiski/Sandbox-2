# Diorama restored browser distribution

Upstream: https://github.com/sloemo01/diorama
Revision: c790df5007be54cccb6c083f7743fae120c89cf4 (v5.7.0).

## What is installed

The complete supplied MIT-licensed toolkit, documentation, templates, verification fixtures, reference media and original water scene. This is a Three.js browser toolkit; upstream has no server backend, accounts, scene editor or complete application shell. No backend was fabricated.

- `original.html`: the original water interface generated by the upstream build (with the documented replay fix).
- `water.html`: the same simulation with a new viewer using the supplied orbit helper, play/pause, deterministic timeline, camera reset and PNG capture.
- Rendering lab: the original synthetic inspection fixture, with all three supplied render styles, assembly/piece selection and clear.
- Showcase: the four original films. Complete source for those narrative scenes is absent upstream. They are recordings, not interactive restorations.
- Source library: all supplied guides and modules. Modules are developer building blocks, not hidden end-user screens.
- Download kit: original source, reference media, runnable offline `OPEN-WATER.html`, build scripts and licences. Opening the HTML requires no sign-in or network.

The preview shell is new navigation; the original water interface remains available separately. Water geometry, materials and choreography are preserved. A small upstream determinism fix resets splash-drop rotations on each burst, preventing previous playback from changing a frozen frame. Both the original view and added viewer include this fix. This is not an animation editor, and no MP4 export feature is claimed.

## Install and run

Node 22 or 24: `npm ci`, `npm test`, `npm run build`.
Serve `dist` using any static server (for example `npm run preview`, which uses Python 3 on port 4185). Vercel: framework Other, build `npm run build`, output `dist`.

Use Chrome, Edge, Firefox or Safari with WebGL2 enabled. Desktop and touch orbit supported. The default original scene is pixel-rendered by design. Performance varies with GPU. Reduced motion starts the added viewer paused. Source library fetches need HTTP; the included standalone water HTML works directly offline.

## Regression checks

`npm test` supplies local Three module paths to upstream tests, replacing the need for the author's absolute Mac directory. `CHROME=/path/to/chromium node templates/qa/education-dock.test.mjs` tests original controls. `CHROME_PATH=/path/to/chromium DIORAMA_FIXTURE_URL=http://127.0.0.1:4185/inspection.html node templates/qa/inspection-browser.mjs` tests the inspection fixture over HTTP. Linux testing uses SwiftShader. Browser controls and deterministic rendering are covered by `node scripts/browser-test.mjs` with `BASE_URL` and `CHROME_PATH` overrides.
