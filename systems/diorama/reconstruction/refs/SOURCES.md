# Reference and source ledger
- Four original MP4 and GIF files in upstream `media/`, reviewed as whole scenes and sampled frames. These are visual/motion references, not rendered backgrounds.
- Upstream `templates/peopleModel.js`, `poses.js`, `geometry.js`, `post.js`, `camera.js`, `orbit.js`: MIT, retained attribution in repository LICENSE.
- New scenery/vehicle/creature geometry is authored from the supplied references. No unreviewed online model or external asset service used; keeping the toolkit's cohesive toy-scale silhouettes rather than mixing unrelated asset styles.
- Frame references captured from pool at12s, bank16s, arena18s, battle20s and loop contact sheets. Choreography derived from README scene descriptions and these recordings; timings of newly authored motion are approximations except documented battle send-out beats.
- Three.js r170 MIT. Browser fonts are local system fonts. No remote runtime dependencies.
