OpenFlow Workflow Studio

Multi-agent workflows with handoffs, parallel layers and human approval Upstream projectRun the desktop app

An interactive model of OpenFlow, not affiliated with its author. It loads the same contract-review workflow file that Sandbox-2's test runs through OpenFlow's real engine. Here each agent's work is done by deterministic extractors over the sample contract, so runs, layers, approvals and structured outputs behave like the app without model keys.

Inspector

Select an agent. Drag to move. Click a right-hand dot, then a left-hand dot, to add a handoff; click a line to remove it.

Timeline

Run the workflow to see layers execute; agents in the same layer run at the same time.

Describe the workflow

Steps separated by “then” become layers; “and … in parallel” makes parallel agents. This stands in for OpenFlow's model-written drafts.

Draft

The draft appears here; apply it to replace the canvas.

Model providers

Each node can use a different provider and model. Keys stay in the desktop app's settings.
