Loopcut Agent Workbench

The AI agent inside a Blender 5.2 fork: how it routes a request, and how it checks that things sit where they should Upstream projectInstall and test code

Loopcut is a desktop app (Blender built from source), so it can't run in a browser. This page runs two of its pieces. Placement checks uses check_contact's verdict and wording code from contact.py, ported line for line, on a scene made of boxes; Loopcut measures real meshes inside Blender. Router uses router.py's parsing and its <routing> note; Claude stands in for Loopcut's router model, whose prompt Loopcut serves from its own servers.

One turn in Loopcut


flowchart TD
  U[User types in the Loopcut panel] --> R{Router: level 0-3}
  R -->|0 question| A[Answer, change nothing]
  R -->|1 small edit| S[Orchestrator edits the scene itself]
  R -->|2 one deliverable| P[Build it, or one worker]
  R -->|3 several| W[One worker each, dry_run first]
  P --> L[run_python in Blender]
  W --> L
  S --> L
  L --> C[check_contact, acceptance checks, camera framing]
  C -->|fail: the move that fixes it| L
  C -->|pass| F[Final reply with what was verified]


      
rests_on, one support at a time


flowchart LR
  A[a's vertices near its lowest point] --> B[split into supports: legs, feet]
  B --> C[vertical lines down onto b]
  C --> D{per support}
  D -->|within tolerance| T[touching]
  D -->|above| FL[floating]
  D -->|below b's top| IN[into / through b]
  T & FL & IN --> V[verdict + move a by 0,0,dz; a lone foot moved by itself]


        
touches and clear_of measure the nearest approach both ways, from every vertex and face centre; inside measures against b's convex hull. A pair is re-measured after every later run_python when the agent asks to watch it.

    

  


  

    
The two red checks

      

        
merge_check.py
The harness expects a checkpoint restore to write a new .blend file. The Loopcut build at the same commit restores in place, which its own unit tests (all 4,196 passing) expect. The harness assertion is older than the code.

        
m4_e2e_check.py
The scripted end-to-end run with workers completes, then the harness reads the contact sheet as a PNG. Loopcut now writes it as a JPEG, so that one assertion fails.

      

      
Both are upstream test files that lag the app. The install, the app and every other check pass; nothing in Sandbox-2 is patched to hide them.
