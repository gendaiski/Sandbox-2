Pake App Builder

Turn a web page or a local build into a small desktop app Upstream projectReal build test

An interactive model of Pake's CLI, not affiliated with its author. The options and their rules come from Pake's own config schema (schema/pake.schema.json), and validation follows its agent contract: one JSON result, exit code 2 for invalid input. The build itself is simulated here; Sandbox-2's CI really builds the sample contract page into a 4.8 MB Linux .deb.

Unknown fields fail fast, values are checked against the schema's types and limits, and explicit CLI flags would win over these fields. A relative url resolves against the working directory, not the config file's folder.

What pake does


flowchart LR
  IN["URL, HTML file
or local folder"] --> V{"Validate options
(schema, agent contract)"}
  V -->|"invalid: exit 2"| ERR["{ok:false, error: INVALID_INPUT}"]
  V --> ICON["Fetch favicon
or use --icon"]
  ICON --> CONF["Write tauri.conf.json
and pake.json into a temp workspace"]
  CONF --> CARGO["cargo build --release
(Tauri shell in Rust)"]
  CARGO -->|"missing Rust or libs: exit 4"| ENV["{error: ENV_MISSING}"]
  CARGO --> BUNDLE["Bundle: dmg / msi / deb / AppImage"]
  BUNDLE --> OUT["{ok:true, outputs:[{path, sizeBytes, format}]}"]
