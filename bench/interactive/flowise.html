Flowise Flow Studio

Build LLM apps and agents by wiring nodes on a canvas Upstream projectRun the real server

An interactive model of Flowise's features, not affiliated with FlowiseAI. Flows really execute here: documents load, split, embed (TF-IDF), and retrieve in your browser. Model calls are answered by an extractive stand-in that quotes the retrieved text, since the page holds no API keys.

Inspector

Select a node to edit its settings. Drag a node by its title. Connect by clicking an output dot, then a matching input dot. Click a wire to remove it.

What happens when you send a message


sequenceDiagram
  participant C as Chat
  participant S as Server
  participant G as Flow graph
  C->>S: POST /prediction/:id {question}
  S->>G: build graph from flowData, find the ending node
  G->>G: init nodes in dependency order (loaders, splitters, embeddings, vector store)
  G->>G: run ending node (chain or agent) with question and memory
  G-->>S: answer + source documents + used tools
  S-->>C: stream tokens, then the final message

What each section here maps to

        
Canvas
Chatflows (LangChain nodes with typed inputs) and Agentflows (step nodes with branches and human approval).

        
Document Stores
Loaders and splitters with chunk preview, upsert into a vector store, retrieval testing.

        
Marketplace
Ready-made flows you load onto the canvas and adapt.

        
Tools
Built-in and custom tools that agents may call.

        
Executions
Each run with the output of every node, for debugging.

        
API & Embed
The prediction endpoint and the embeddable chat widget.
