from chunk_flow.chunking import StrategyRegistry
from chunk_flow.evaluation import EvaluationPipeline

chunker = StrategyRegistry.create("recursive", {"chunk_size": 600})
result = await chunker.chunk(text)
pipeline = EvaluationPipeline(metrics=["semantic_coherence", "boundary_quality"])
scores = await pipeline.evaluate(result.chunks, embeddings)

    

  


  

    

      
Architecture


flowchart LR
  TXT["Text, Markdown, HTML"] --> REG{"Strategy registry
fixed_size, recursive, markdown,
html, semantic, late"}
  REG --> CH["Chunks"]
  CH --> EMB["Embedding providers
Hugging Face, OpenAI"]
  EMB --> EV{"Evaluation pipeline"}
  EV --> SEM["Semantic: coherence, boundaries,
stickiness, topic diversity"]
  EV --> RET["Retrieval: NDCG, Recall@k,
Precision@k, MRR"]
  EV --> RAG["RAG: context relevance, faithfulness,
context precision and recall"]
  SEM --> CMP["Comparison and ranking"]
  RET --> CMP
  RAG --> CMP


      
Late chunking


flowchart TB
  DOC["Whole document"] --> ENC["Embed the full text once"]
  ENC --> TOK["Token vectors with document context"]
  TOK --> POOL["Pool tokens inside each chunk span"]
  POOL --> V["Chunk vectors that remember their context"]


        
Here late chunking is approximated by mixing each chunk's vector with the document's. Sandbox-2's Studio (systems/chunckerflow/studio) runs the real API with real embeddings.
