Extension, core and GUI


flowchart LR
  IDE[VS Code or JetBrains extension] <-->|messenger protocol| CORE[core: config, context providers, LLM adapters, indexing]
  GUI[React GUI in a webview: chat, edit, agent] <-->|postMessage| IDE
  CORE --> CFG[(config.yaml: models with roles, rules, prompts, MCP servers)]
  CORE --> IDX[(codebase index: embeddings and full text)]
  CORE --> LLM[providers: Anthropic, OpenAI, Ollama, Mistral...]
  CLI[cn CLI: the same core in a terminal] --> CORE


      
Autocomplete


flowchart TB
  K[keystroke, debounced] --> PS[constructPrefixSuffix around the cursor]
  PS --> SN[snippets: recent files, imports, clipboard]
  SN --> T[getTemplateForModel: FIM tokens or the hole filler]
  T --> M[autocomplete model]
  M --> F[filtering: stop tokens, brackets, repetition]
  F --> G[ghost text: Tab accepts]
