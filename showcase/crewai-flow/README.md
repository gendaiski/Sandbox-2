# CrewAI Flow Visualization preview

This is the original interactive **Flow Visualization** generated by the open-source CrewAI `Flow.plot()` implementation from `crewAIInc/crewAI` version `1.15.30`, commit `38db11e3324fa0e23beb5eecd0d87e8e31ca2bb0`. It depicts a local test Flow that prepares an input, runs a two-agent Crew, and saves a report. Node details, zoom, theme, and graph navigation run in the browser.

The browser assets are kept beside the generated HTML because the original export referenced third-party CDNs that were unavailable in the review browser. The CrewAI logo comes from the cloned repository. Vis Network, Lucide, Prism, and Inter are included with their licence files in `vendor/`.

This page is a **visualization of a tested Flow**. It is not the CrewAI AMP control plane, and it cannot create or run new agents from GitHub Pages. The AMP browser application is hosted separately at https://app.crewai.com and requires an account. The open-source CLI and framework are installed in the Codex cloud workspace at `/workspace/CrewAI-runtime`; see its `START_HERE.md` for the installation record.
