Methodology

How Website Twin assembled this legal AI directory, checked its source data, and marks the limits of what has been independently verified.

Directory review · October 2026
By Website Twin5 min read

On this page

What this directory measures

This directory is a source-backed catalog of 22 AI applications from a public Legal Benchmarks page saved on 24 October 2026. It makes the captured cards and their embedded profile fields easier to search and inspect. It is not a new ranking of products.

Ratings, review counts, certifications, and benchmark figures shown in the profiles are the original publisher's reported values. We checked that we copied those values correctly from the supplied file. We did not independently verify the underlying reviews, rerun the benchmark tasks, or award any certificates.

Reading rule: a copied score is source-reported evidence, not Website Twin's verdict.

How we prepared the review

1. Preserve

We retain the user-supplied public HTML, its canonical URL, receipt date, byte count, and SHA-256 checksum. These identify the exact files used to build this review.

2. Extract

We read the directory's embedded application records and export structured cards and profiles. The page's search, filters, and profile views use those captured fields.

3. Reconcile

For all 22 entries, we compared names, descriptions, use cases, ratings, and review counts against the embedded source data. We also checked the resulting pages at desktop and mobile widths.

4. Display gaps

When the capture does not contain a field, the profile says so. The Claude profile includes only the review-summary excerpt visible in a user-supplied screenshot; no missing reviews have been reconstructed.

How to read the results

Ratings and review counts are values published in the snapshot. Their presence does not mean we authenticated the reviewers.

Certifications and badges are labels attributed to the source publisher. Website Twin has not awarded them.

Benchmark figures come from embedded source data. The publisher's testing and grading procedure is described in its captured methodology. We did not run that procedure.

Descriptions and use cases represent the source directory's classification at the time of capture. Products may have changed since then.

Limitations

  • Snapshot: the captured directory reflects the saved page on 24 October 2026, not necessarily today's website.
  • No independent evaluation: we have not tested any of the listed products or audited the publisher's benchmark tasks.
  • Incomplete review evidence: individual review texts and rating distributions were not present in the supplied directory HTML.
  • Appearance: the original site's CSS and full image set were not supplied, so this page uses a close local reconstruction.

Independent testing: proposed next stage

Status · Not yet run

A separate evaluation would need documented task scope, lawful product access, repeatable inputs, a published scoring rubric, qualified human review, and versioned evidence. No such independent scores are included in this directory.

  1. Define the legal tasks, jurisdictions, file formats, and pass criteria.
  2. Confirm product permissions, privacy requirements, account plans, and costs.
  3. Run comparable workflows and preserve submitted files and outputs.
  4. Have qualified reviewers assess substance and usability, resolving disagreements.
  5. Publish dates, versions, limitations, and an audit trail for any result.

This is a plan for future work, not a claim that the tests have been performed.
