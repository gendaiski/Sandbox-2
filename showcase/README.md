## Rebuild and verify

Run `python3 scripts/build_showcase.py` to regenerate the hub, 33 system pages, 33 system launch pages, 14 landing routes and 14 landing launch pages from `showcase/catalog.json`, `showcase/scenes.py` and `showcase/design_scenes.py`. Run `python3 scripts/verify_showcase.py` to check links and assets; add `--browser` after installing Playwright and Chromium for responsive rendering and interactive control checks. Rebuild and verify the original landing applications with `python3 scripts/export_native_landings.py` and `python3 scripts/verify_native_landings.py`.

To reproduce the original MacBook app build, run `npm ci` inside `vendor/showcase/macbook`, then `python3 scripts/prepare_macbook_native.py` from the repository root, then `npm run build` inside the app. The preparation script copies the already installed Three.js Draco decoder into the ignored checkout and sets the original model loaders to use it locally. It does not modify the committed showcase.

For the 14 original landing applications, expand the sparse checkout with `git -C vendor/showcase/landing-pages sparse-checkout set landing-pages`, then run `pnpm install --frozen-lockfile`, `pnpm build` and `pnpm typecheck` in each folder under `vendor/showcase/landing-pages/landing-pages/`. Build before type checking Aparté so Next.js generates its type declarations. Ten were exported to GitHub Pages with original client interactions; four require a Node server.
