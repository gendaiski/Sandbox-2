Setup guide ↗

FIRST-TIME CONNECTION

Run the Onboarding System on your computer

Open PowerShell in your existing Sandbox-2 checkout. Run one command at a time and stop if a step fails. Docker is not needed for the supported content setup.

  1. Check Python 3.11 or newer. If this fails or opens the Microsoft Store, install Python 3.12 from python.org, select “Add python.exe to PATH,” and reopen PowerShell.python --version
  2. Update your checkout.git pull --ff-only
  3. Create the isolated environment. Continue only after this succeeds.python -m venv .venv-onboarding
  4. Install the pinned dependencies..\.venv-onboarding\Scripts\python.exe -m pip install -r onboarding\requirements.txt
  5. Start the runner and open the local address it prints. On your computer, the page opens directly without a code..\.venv-onboarding\Scripts\python.exe -m onboarding.server
Detailed Windows guide ↗

The Windows py launcher is optional. The runner supports only reviewed installation paths; other projects receive a bounded content setup or an explicit blocker.
