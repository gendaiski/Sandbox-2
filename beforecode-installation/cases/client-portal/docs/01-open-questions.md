# Open Questions

These questions should be answered before serious implementation starts. They exist to prevent AI agents and developers from inventing unconfirmed behavior.

## Product

- What user or business problem does this solve?
- What should be explicitly excluded from v1?
- What is the primary success metric for v1?

## Users and UX

- What is the first successful action a new user should complete?
- Which screens or flows are critical for MVP?

## Technical

- Which frontend, backend, database, and auth stack should be used?
- What data must be stored, protected, exported, or audited?
- Which integrations or third-party services are required?

## QA and Release

- Which workflows must never break?
- What should be tested manually before release?
- What performance, security, or reliability constraints matter for v1?
