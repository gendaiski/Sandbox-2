# Swarm frontend previews

Public access hub: https://swarm-apps-original.aelgendy673996.chatgpt.site

Includes AgentSwarms v1.6.0, Agent Swarm Studio, Agent Swarm Monitor and Multi-Agent AI Swarm browser pages. Original components/assets are used; this is not a full agent runtime installation. No credentials, paid calls, Docker workloads, host mounts or fake completed cases are included. Source pins/overlays/build recipes are in each systems package. Existing AgentSwarms is reused.

Route/action QA was performed against a plain local static server in Chromium, including browser reload persistence. Public deployment is verified by the Sites deployment result; network policy may prevent an independent Chromium visit to the public hostname. Root run.sh/CI registration is unchanged.
