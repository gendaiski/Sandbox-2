# Parallel additions: Free Blueprints and yFiles demo reference

## Free Blueprints

Source: https://github.com/agent-blueprint/free-blueprints at 2cf1f63ccd1f2312e25ac4b1bcae2bf2db02f867. This is an MCP server with two read-only tools, two five-role blueprint manifests and twenty original documents; it contains no browser UI or implemented agent workflow harness. The actual MCP builds and both stdio/Worker transport contracts were verified locally.

Published convenience source reader: https://free-blueprints-original.aelgendy673996.chatgpt.site . It is explicitly an added reader, not the original interface of a web product. Exact source text, full-text search, document/JSON/ZIP exports, refresh and iPad viewport were checked. No public MCP backend, model calls, agents or business integrations were deployed. Rebuild recipe, exact-content reports and source pin are in systems/free-blueprints.

## yFiles for HTML demos

Original official experiences: https://yfiles.com/demos/ and https://yfiles.com/play . No replacement catalogue or cloned UI was fabricated. The public Git repository omits the commercial rendering runtime. A valid corresponding yFiles distribution/license is required for local running and governs redistribution; no license key was invented and no runtime was installed, bought or rehosted.

Pinned source reference and setup preflight/specification are in systems/yfiles-demos. Official website access from this managed environment is blocked (CONNECT403/ERR_TUNNEL_CONNECTION_FAILED), so live demo execution and physical iPad behavior were not verified. Source inspection and the absence of runtime are documented; official links are handed off as original hosted examples, not as a deployment created in this task.

Existing user projects and backends remain unchanged. The source gitlinks are references to the named upstream repositories. The packages are independent of the current root launcher and CI matrix.
