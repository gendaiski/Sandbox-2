Convert PDFs, clean the Markdown, inspect and enrich chunks before indexing Upstream projectTest of the real backend

An interactive model of Chunky, not affiliated with its author. The sample PDF is really parsed in your browser (pdf.js) and converted to Markdown; cleanup, chunking, hashing and enrichment run here too. Server-only converters (Docling, MarkItDown, LiteParse, VLM, cloud APIs) are listed but run only on Chunky's backend. Enrichment uses extractive heuristics in place of an LLM.

Each version records the SHA-256 of the Markdown it came from. Edit the Markdown and the version is marked stale: it stays readable but must be regenerated before it can replace the current one.

The Sandbox-2 test drives these endpoints on the real backend: upload, SSE conversion, four splitters, saving and reloading a version, Markdown edits, and upstream's 53 unit tests.

Chunky's real UI runs with vendor/chunky/start_all.sh; its backend is tested in systems/chunky.
