AI Agents from Scratch

One agent built in 12 lessons from a single LLM call: no frameworks, no hidden reasoning Upstream projectInstall and Agents Lab

The 12 lessons and 6 diagrams from pguso/agents-from-scratch. The repository runs a local model through llama.cpp; here Claude stands in for that model and receives the repository's exact prompts, recorded from its own Agent class. The same retries, JSON parsing, stop sequences, tools, memory and graph execution apply. Installed locally, Agents Lab runs all of it on your own GGUF model.
