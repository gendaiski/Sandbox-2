RAG-Anything Graph Lab

Multimodal documents into a knowledge graph you can query Upstream projectRun the Workbench (real backend)

An interactive model of RAG-Anything's pipeline, not affiliated with HKUDS. The sample PDF is parsed in your browser into a MinerU-style content list (plus one example figure and equation, since the sample has none), then entities, relations and the graph are built by rules and queried in LightRAG's five modes. In RAG-Anything an LLM does the extraction and answering; Sandbox-2's Workbench runs that for real with Claude or OpenAI.

Pipeline


flowchart LR
  DOC["PDF, Office, image"] --> MINERU["MinerU parser
layout + OCR"]
  MINERU --> CL["Content list
text, table, image, equation"]
  CL --> TXT["Text chunks"]
  CL --> MOD{"Modal processors"}
  MOD --> IMG["Image: VLM caption"]
  MOD --> TAB["Table: analysis"]
  MOD --> EQ["Equation: explanation"]
  TXT --> EX["Entity + relation extraction (LLM)"]
  IMG --> EX
  TAB --> EX
  EQ --> EX
  EX --> KG[("LightRAG graph
+ vector stores")]
  KG --> Q["Query: naive, local,
global, hybrid, mix"]


      
Query modes


flowchart TB
  QUERY["Question"] --> KW["Keywords: low-level (entities)
and high-level (themes)"]
  KW --> LOCAL["local: matching entities,
their neighbours and source chunks"]
  KW --> GLOBAL["global: matching relations
and the sections they span"]
  QUERY --> NAIVE["naive: vector search on chunks"]
  LOCAL --> HYB["hybrid = local + global"]
  GLOBAL --> HYB
  HYB --> MIX["mix = hybrid + naive"]
  NAIVE --> MIX


        
Sandbox-2's Workbench (systems/rag-anything/serve.sh) is a FastAPI backend over the real library: upload, MinerU parsing, graph building with Claude or OpenAI, and these query modes.
