What each section here maps to

        

          
Tracing
Nested observations with timing, token usage, cost, levels and linked prompt versions.

          
Sessions
Traces grouped by session id, replayed as a conversation.

          
Prompts
Versioned prompts with labels, variables, config and diffs; compiled in a playground.

          
Datasets
Golden items, experiment runs over prompt versions, evaluator scores per run.

          
Evaluation
Human annotation queues, score configs, and LLM-as-a-judge evaluators on live traces.

          
API keys
Project-scoped key pairs and the SDK setup that sends traces.
