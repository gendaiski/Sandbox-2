Two canvases, one object model


flowchart LR
  U[Pointer and keyboard] --> UC[upper canvas: selection, controls, brush strokes]
  UC --> EV[events: mouse:down, object:moving, object:modified]
  EV --> OM[object model: Rect, Circle, IText, Path, Group, FabricImage]
  OM --> R[renderAll: draws each object with its transform matrix]
  R --> LC[lower canvas: what you see]
  OM --> S[toObject / toJSON] --> J[(JSON)]
  J --> L[loadFromJSON] --> OM
  OM --> SVG[toSVG]
  OM --> F[filters: WebGL or Canvas 2D backend]


      
What each piece does

        

          
Canvas
Interactive canvas: selection, controls, free drawing, events. StaticCanvas is the render-only variant used for exports and node.

          
FabricObject
Base of every shape: position, origin, scale, angle, skew, fill, stroke, shadow, clipPath, controls.

          
IText / Textbox
Editable text with per-character styles; Textbox wraps to a width.

          
Group / ActiveSelection
Nested objects with a layout manager; a multi-selection is a temporary group.

          
Brushes
Pencil, Circle, Spray and Pattern brushes turn strokes into Path or Group objects.

          
Filters
25 image filters, run on WebGL when available and Canvas 2D otherwise.

          
Serialization
toJSON and loadFromJSON round-trip the scene; toSVG and toDataURL export it.
