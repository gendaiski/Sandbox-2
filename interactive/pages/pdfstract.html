PDFStract Compare

Extract a PDF with several libraries, compare the results, then chunk them Upstream projectRun the real app

An interactive model of PDFStract, not affiliated with its author. Four extractors really run in your browser on the PDF (built on pdf.js, imitating each library's output style); the ML and OCR libraries are listed with what they add but run only on PDFStract's server.

Every extraction run is kept here (in this browser), like PDFStract's library of results.

Command line

pdfstract libs                                  # which libraries are installed
pdfstract convert service_agreement.pdf --library pymupdf4llm --format markdown
pdfstract compare service_agreement.pdf --libraries pymupdf4llm,markitdown,docling
pdfstract chunk output.md --chunker recursive --chunk-size 500

Python

from pdfstract import PDFStract

ps = PDFStract()
md = ps.convert("service_agreement.pdf", library="pymupdf4llm")
chunks = ps.chunk(md, chunker="recursive", chunk_size=500)
print(len(chunks), chunks[0]["text"][:80])

Web API

GET  /libraries                      installed libraries and status
POST /convert   (file, library)      one extraction
POST /compare   (file, libraries)    starts a comparison task
GET  /compare/{task_id}/results      per-library output and timing
GET  /compare/{task_id}/download     all outputs as a zip
