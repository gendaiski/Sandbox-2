CAMEL Role-Playing Studio

Two agents, an AI user and an AI assistant, solve a task by instruction and solution Upstream projectInstall and test code

This runs CAMEL's RolePlaying society the way camel.societies.RolePlaying does: the same AI Society prompts, the same opening message, and the same stop word, with Claude playing both agents from this page on your own Claude account. The role lists come from CAMEL's data/ai_society files.

Session

Open this page in Claude to run a session. The Prompts tab shows exactly what each agent would receive.

Each turn is two calls (user agent, then assistant agent), plus one for the task specifier.

Conversation

Pick two roles and a task, then start. Try a Stock Trader with a Python Programmer.

RolePlaying


sequenceDiagram
  participant S as Task specifier
  participant U as AI user (ChatAgent)
  participant A as AI assistant (ChatAgent)
  S->>S: TASK_SPECIFY_PROMPT: make the task specific
  A->>U: init_chat: start giving instructions
  loop each step
    U->>A: Instruction and Input
    A->>U: Solution, ending in Next request
  end
  U-->>A: CAMEL_TASK_DONE ends the session
