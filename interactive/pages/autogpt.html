AutoGPT Workflow Builder

Wire blocks into a workflow and run it; the library holds all 608 blocks in the platform's source Upstream projectInstall and test code

A model of the AutoGPT Platform builder. Blocks, their inputs, outputs, ids and categories come from autogpt_platform/backend/backend/blocks; the workflow JSON uses the platform's own node and link fields. Text, logic and AI blocks run here, with Claude answering for the AI blocks on your own Claude account; blocks that call outside services run only on the AutoGPT server.

Drag a block by its title. To connect, click an output dot on the right of one block, then an input dot on the left of another; click a wire to select it. AI blocks need this page open in Claude; the rest run anyway.
