LobeHub Chat Workspace

Agents, topics and a model catalog of 85 providers, from LobeHub's own model bank Upstream projectInstall and test code

A model of LobeHub's chat workspace. The default Lobe agent uses the system role LobeHub generates (packages/builtin-agents, inbox), and the catalog lists the providers and chat models in packages/model-bank. Replies come from Claude through this page, on your own Claude account, whatever model the agent is set to; topics are kept in this browser only.

A chat turn

sequenceDiagram
  participant U as You
  participant A as Agent (system role, model, plugins)
  participant R as Agent runtime
  participant M as Model provider
  U->>A: message in a topic
  A->>R: system role + last N messages + tools
  R->>M: provider SDK (openai, anthropic, google...)
  M-->>R: streamed tokens, tool calls
  R-->>U: streamed reply, saved to the topic
