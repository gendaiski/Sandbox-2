One call


flowchart LR
  S[Signature: fields, types, instructions] --> M[Module: Predict, ChainOfThought, ReAct]
  M --> A[Adapter: ChatAdapter formats messages]
  D[(demos)] --> A
  A --> LM[dspy.LM: any provider via LiteLLM]
  LM --> P[Adapter.parse: split on field markers, cast types]
  P --> R[dspy.Prediction]


      
Compiling a program


flowchart LR
  T[(trainset)] --> O[Optimizer]
  MET[metric] --> O
  PR[program] --> O
  O -->|BootstrapFewShot: keep passing traces as demos| C[compiled program]
  O -->|MIPROv2, GEPA: propose and search instructions| C
  O -->|BootstrapFinetune: train weights| C
  C --> E[dspy.Evaluate on devset]
