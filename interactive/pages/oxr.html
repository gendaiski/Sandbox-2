OXR Layout Lab

Document layout analysis: find regions, read them in order, export Markdown or JSON Upstream projectSoMark's hosted demo

An interactive model of OXR's pipeline, not affiliated with SoMark. OXR's own detector is a neural model that needs an NVIDIA GPU; here a rule-based detector runs on the PDF's text layer in your browser so every step (regions, classes, confidence, reading order, export) is live. For OXR's real output, use SoMark's hosted demo or the API tab.

Run the real model
git clone https://github.com/SoMarkAI/OXR && cd OXR
pip install -e .            # CUDA GPU required for the model
python demo.py --input service_agreement.pdf --output out/ \
  --keep_header_footer false

        
Sandbox-2's test runs OXR's 622 upstream unit tests (2 fail: the demo's keep_header_footer default) and drives its parsing pipeline against a stand-in layout service, since CI has no GPU.

      
Free hosted API
curl -X POST https://free-oxr.somark.ai/api/v1/parse \
  -F "file=@service_agreement.pdf" \
  -F "output_format=markdown"

        
This uploads the document to SoMark. The Sandbox-2 CI can do the same when run with the oxr_free_api option.

    

  


  

    

      
OXR pipeline


flowchart LR
  IN["PDF or image"] --> RAST["Rasterize pages"]
  RAST --> DET["Layout detector
(OXR model, GPU)"]
  DET --> REG["Regions with class + confidence
title, text, table, figure,
formula, header, footer"]
  REG --> REC{"Per-region recognition"}
  REC --> T["Text OCR"]
  REC --> TB["Table structure to HTML"]
  REC --> F["Formula to LaTeX"]
  T --> ORD["Reading order"]
  TB --> ORD
  F --> ORD
  ORD --> OUT["Markdown / JSON"]


      
What runs in this page


flowchart LR
  PDF["pdf.js text layer
(glyph boxes, fonts)"] --> LINES["Lines by baseline"]
  LINES --> BLOCKS["Blocks by vertical gap
and left edge"]
  BLOCKS --> CLS["Rules: position, size,
weight, columns"]
  CLS --> ORDER["Order: top to bottom,
column by column"]
  ORDER --> EXP["Markdown, JSON, HTML"]


        
The rules stand in for the neural detector so the downstream steps can be explored. Scanned pages have no text layer and need the real model.
