Excerpts sent with the question

Where Claude Code reads each piece

  P --> ST[.claude/settings.json: permissions, hooks, env]
  P --> AG[.claude/agents/*.md: subagents with tools and model]
  P --> CO[.claude/commands/*.md: slash commands]
  P --> SK[.claude/skills/*/SKILL.md: skills loaded on demand]
  P --> RU[.claude/rules/*.md: path-scoped rules]
