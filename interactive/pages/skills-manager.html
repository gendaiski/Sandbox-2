Skills Manager App

The app's own interface, built from its source, managing skills across 56 coding agents Upstream projectInstall and test code

This is Skills Manager 1.43.0's real React interface, built from vendor/skills-manager/src with two changes (in-memory routing and inlined agent icons). Its Rust backend is replaced by a stand-in that answers the same Tauri commands from memory: the 56 agents from tool_adapters.rs, real SKILL.md files, presets and a project. Nothing here touches your disk; changes last until you reload.

Try: Library, open a skill and toggle agents on its card; Presets in the sidebar; an agent under Global Workspace; the Sandbox-2 project; Settings.

The desktop app


flowchart LR
  UI[React UI in a Tauri webview] -->|invoke: 123 commands| RS[Rust core]
  RS --> LIB[(central library: ~/.skills-manager/skills)]
  RS --> DB[(SQLite: skills, targets, presets, projects, tags)]
  RS --> AD[tool adapters: 56 agents and their skills folders]
  AD -->|symlink or copy| AG[~/.claude/skills, ~/.codex/skills, ~/.cursor/skills ...]
  RS --> GIT[git: installs, updates, backups]
  CLI[skills-manager-cli] --> RS
  AGT[Claude Code, Codex... via the manage-skills skill] --> CLI
