# Individual repository reports

Create one report for each queue item after investigating and setting it up. Name it `01-rehan243-agentic-ai-workflows.md`, etc., preserving the queue number. Each report must distinguish verified behaviour from a successful clone, install, build, or startup message.

Required fields: queue number and repository, full GitHub URL, **verbatim** GitHub About description (or explicit missing-description statement), optional separately labelled README-based summary, exact website listed on GitHub and its verified type, verified official website or explicit absence, relevant official docs/demo, actual project type, purpose, status, installed/prepared version and location, verified usage address or command, checks marked PASS/FAIL/NOT VERIFIED/NOT APPLICABLE with evidence, remaining limitations or required actions, and source links. Never include secrets.

The tracker starts with all repositories `QUEUED`; no individual report is considered complete until its actual investigation and verification have been recorded.
