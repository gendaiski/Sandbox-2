# Superset — agentic desktop IDE

The requested [repository](https://github.com/superset-sh/superset) contains the original Electron IDE, web apps, mobile app and supporting packages. Inspected source: `41b3a2adfa6897bc752ccba36956e0ff10e03abb`; latest inspected desktop release: `desktop-v1.40.0`.

**Status on the user's Windows computer: BLOCKED.** The [official README](https://github.com/superset-sh/superset/blob/main/README.md#install) states “Windows: not yet available,” and the release publishes no Windows installer. The original desktop experience cannot be installed there using a supported upstream build. No substitute interface has been created.

The original application can be obtained from the [official releases](https://github.com/superset-sh/superset/releases/latest) on macOS or Linux. Its documented starting workflow is: install the app, add a repository, create a workspace, select an agent, inspect its changes, run tests, and preview the result. That workflow has **not been verified** here because no supported target was connected for this application. Start/stop/restart are therefore **NOT APPLICABLE** to the user's Windows computer.
