# Engineering Collection

The [Onboarding System](../../showcase/onboarding-system/index.html) presents these as filtered views of the ordered 50-item queue. The views are browsing aids. They do not install or run a repository.

## Architecture & diagrams

Queue items 04, 40, 41, and 43–49: Archify, Joint, System Architecture Generator, Git Architecture Diagram, Terravision, SeeCode, SVG Diagram, Vibex, Dashmotion, and qgraphflow. These include a library, agent skills, diagram generators, and source analysis tools. Each needs its own investigation and supported setup.

## Database

Queue items 20, 21, 22, 24, 25, 27, 32, 33, 39, and 50: NocoDB, GitHubDB, Awesome Vector Databases, seekdb, LangChain VectorDB Learning, Directus, NocoBase, Teable, Rowy, and Design Microservices Architecture with Patterns & Principles.

The collection includes database engines, data applications, curated resources, and learning material. Item 50 is an architecture learning resource that covers database patterns; it is not a database runtime. The project type and completion status for each item must be verified individually before calling it installed.

The [installation tracker](INSTALLATION_TRACKER.md) holds the GitHub About descriptions, listed website links, source URLs, and current statuses. The [category map](REPO_CATEGORIES.json) supplies the Repo Category column in the interactive table.
